FLEX 스페인어

공기업·공무원·기업 어학 가산점 전략 과정

한국외국어대학교가 주관하는 FLEX(Foreign Language EXamination) 스페인어는 공무원·공기업·대기업 어학 가산점, 외국어 특기자 전형에 활발히 활용되는 국내 공인 시험입니다. 듣기·읽기(1,000점 만점) 고득점에 필요한 문법·어휘·속독·청취 전략과, 선택형 말하기·쓰기 대비까지 한 과정에 담았습니다.

수강 상담 신청커리큘럼 보기
대상FLEX 700점 이상 목표자 / 가산점·특기자 전형 준비생
기간12주 (주 2회, 회당 100분)
총 시수40시간 + 실전 모의고사 4회
목표듣기·읽기 800점+ (등급 2A 이상) / 말하기·쓰기 선택 대비
수업 형태실시간 온라인 소그룹 (최대 8명) / 1:1
교재다인에듀 FLEX 문법·어휘 정리집 + 기출 유형 분석집

학습 목표

  • FLEX 듣기 4개 파트·읽기 4개 파트의 문항 유형과 출제 포인트를 완전히 파악한다
  • 빈출 문법(시제·서법·대명사·전치사·접속사) 200개 포인트를 체계적으로 정리한다
  • 시사·경제·문화 어휘 1,500개를 주제별로 암기하고 문맥에서 활용한다
  • 긴 지문을 1분 내 스캐닝하는 속독과 선택지 소거법을 체득한다
  • 선택 영역(말하기·쓰기)의 평가 기준에 맞춰 답안을 구성한다

수업 방식

  1. 기출 유형 기반 자체 모의고사 4회 + 문항별 오답 분석
  2. ‘문법 포인트 카드 200’ 매일 10분 플랫폼 복습
  3. 듣기 음원은 1.0x → 1.2x 속도 단계별 훈련
  4. 목표 점수별(700/800/900) 맞춤 학습 경로 제공

자주 묻는 질문

DELE와 FLEX 중 무엇을 봐야 하나요?

국내 공무원·공기업 가산점 및 특기자 전형은 FLEX, 해외 유학·취업은 DELE가 유리합니다. 목표에 따라 두 과정을 연계 수강할 수도 있습니다.

점수 유효기간은?

일반적으로 성적 발표일로부터 2년입니다. 활용 기관별 기준은 별도 확인이 필요합니다.
