Gramática del Uso 초급반

문법의 뼈대를 세우는 가장 확실한 길

Gramática de uso del español(SM 출판사) A1–A2 레벨을 바탕으로, 스페인어 문법의 토대를 ‘설명 → 연습 → 말하기 적용’ 3단계로 완성하는 과정입니다. 매 단원 왼쪽 페이지의 규칙을 한국어로 명쾌하게 풀어 주고, 오른쪽 페이지 연습문제를 함께 풀며 오류를 즉시 교정합니다.

학습 목표

  • 명사·관사·형용사의 성수 일치를 자동으로 처리한다
  • ser·estar·hay·tener의 쓰임을 상황에 맞게 구분한다
  • 현재·현재완료·부정과거·불완료과거의 형태와 용법을 익힌다
  • 직접·간접 목적격 대명사와 재귀동사를 정확히 배열한다
  • 명령형·ir a + 동사원형·gustar 구문으로 일상 표현을 완성한다

수업 방식

  1. 매 단원 ‘규칙 10분 설명 → 교재 문제 풀이 → 응용 말하기’ 루틴
  2. 플랫폼 자동 채점 퀴즈로 복습률 관리
  3. 학습자 오류 데이터를 모아 개인별 ‘자주 틀리는 문법 TOP 10’ 제공
  4. DELE A2 과정과 연계 시 수강료 할인
